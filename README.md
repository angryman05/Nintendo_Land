# Nintendo_Land
***Short description: high school project that I did in 2023.***
This is sort of a **Steam** copy but made for **Nintendo** games. I had to make a project in C# where I was supposed to use sql databases.
## What can I do here?
Well, you can create an account,change your profile picture and view video game listings.
In the video game listing you can rate the video game from 1 to 5 stars or buy it.
The app is not as complete as I wanted it to be but I was enough for that period.
A remake will come when I have the time to make it(complete shop features and all).
This is just a project that shows my love for Nintendo games. Thats all.
